#  Airline Reservation System

## Overview
This project is a **Java-based Airline Reservation System** developed for the **Object-Oriented Programming (OOP) module**.  
It demonstrates the use of OOP principles such as **classes, objects, inheritance, polymorphism, and encapsulation** in building a real-world style application.

## Features
- Add, update, and delete flight details  
- Manage passenger information  
- Book and cancel reservations  
- Display available flights and booking history  
- Console-based interface for user interaction  

## Technologies Used
- **Java** (Core language)  
- **NetBeans IDE** (Project setup and management)  
- **OOP Concepts** (Inheritance, Polymorphism, Abstraction, Encapsulation)  
- **Collections Framework** for data handling
